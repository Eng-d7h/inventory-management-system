# MVP - Inventory, Goods & Supplier Management System

## Inside the MVP (we will build these)

- [ ] 1. Authentication: register and login with email and password
- [ ] 2. Products management: add, view, edit, deactivate
- [ ] 3. Suppliers management: add, view, edit
- [ ] 4. Inventory: Stock In and Stock Out
- [ ] 5. Stock history: table of all inventory transactions
- [ ] 6. Low stock alerts: red badge when currentStock <= minimumStock
- [ ] 7. Simple dashboard: stat cards and recent transactions

## Outside the MVP (postponed)

- Purchase orders
- Reports
- Advanced roles (Inventory Manager, Purchasing Manager)
- Product image upload
- Returns and manual stock adjustments

## Rule

If a new idea comes up while building, check this file first.
If it is not inside the MVP, write it down for later and do not build it now.
